# Database Anggota Offline

Aplikasi Android offline untuk mencari dan menampilkan data anggota koperasi.

## Fitur

- Pencarian berdasarkan nama anggota
- Mendukung pencarian sebagian nama
- Menampilkan seluruh data anggota
- Dapat menampilkan lebih dari satu hasil jika terdapat nama yang sama
- Tidak membutuhkan koneksi internet setelah aplikasi terpasang
- Data tersimpan secara lokal di perangkat

## Data

Database berisi data anggota dengan 18 kolom:

1. Nomor Urut
2. Nomor Anggota
3. Nama Anggota
4. Alamat
5. Tanggal Pinjam
6. Tanggal Angsur Akhir
7. Tanggal Angsur Bunga Akhir
8. Tanggal Jatuh Tempo
9. Besar Pinjaman
10. Tunggakan SW
11. Tunggakan Pokok
12. Tunggakan Bunga
13. Total
14. Sisa Pinjaman
15. Jumlah Sibuhar
16. Jumlah Saham
17. Selisih Simpanan dan Pinjaman
18. Keterangan

## Cara Menggunakan

1. Buka aplikasi.
2. Masukkan nama anggota pada kolom pencarian.
3. Tekan tombol **CARI**.
4. Data anggota yang sesuai akan ditampilkan.
